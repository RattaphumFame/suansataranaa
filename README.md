# Bangkok Parks API

API สำหรับค้นหาสวนสาธารณะกรุงเทพฯ โดยดึงข้อมูลจากตาราง `bangkok_parks`
ในฐานข้อมูล MySQL (`bangkok_data`) ที่ import ไว้แล้ว

## Flow การทำงาน (ตามไดอะแกรม)

1. ผู้ใช้เลือกเขตที่ต้องการค้นหา
2. ระบบเรียกข้อมูลจาก MySQL
3. ถ้าดึงข้อมูลไม่สำเร็จ -> ส่ง error กลับ (HTTP 500 พร้อมข้อความ)
4. ถ้าสำเร็จ -> คัดกรองตามเขตที่เลือก -> จัดรูปแบบผลลัพธ์ -> ส่งกลับเป็นรายการ

> หมายเหตุ: ตอนนี้ยังไม่มีพิกัด (lat/lng) ของแต่ละสวนในฐานข้อมูล
> ดังนั้นยังทำ "เรียงตามระยะทางจากตำแหน่งปัจจุบัน" ไม่ได้ ทำได้แค่คัดกรองตามเขตก่อน

## ติดตั้ง

```bash
npm install
```

## ตั้งค่าฐานข้อมูล

โปรเจกต์นี้อ่านค่าการเชื่อมต่อฐานข้อมูลจากไฟล์ `.env` ผ่าน `@nestjs/config`
(ดู `src/app.module.ts`) ไม่ต้องแก้โค้ดตรงๆ อีกแล้ว

1. คัดลอกไฟล์ตัวอย่าง:
   ```bash
   cp .env.example .env
   ```
2. เปิด `.env` แล้วใส่ค่าจริงของคุณ:
   ```
   DB_HOST=localhost
   DB_PORT=3306
   DB_USER=root
   DB_PASS=ใส่_password_ตรงนี้
   DB_NAME=bangkok_data
   ```

## รันโปรเจกต์

```bash
npm run start:dev
```

จะรันที่ http://localhost:3000

## Endpoints

| Method | Path                          | คำอธิบาย                          |
| ------ | ----------------------------- | ---------------------------------- |
| GET    | `/parks/search`                | สวนสาธารณะทั้งหมด                  |
| GET    | `/parks/search?district=...`   | คัดกรองตามเขต                      |
| GET    | `/parks/districts`             | รายชื่อเขตทั้งหมด (ทำ dropdown)     |
| GET    | `/parks/:id`                   | รายละเอียดสวนสาธารณะทีละแห่ง       |

## ทดสอบด้วย Bruno

เปิดแอป Bruno -> Open Collection -> เลือกโฟลเดอร์ `bruno-collection`
ในโปรเจกต์นี้ -> เลือก environment "Local" -> กดยิง request ทดสอบได้เลย
(ต้องรัน `npm run start:dev` ค้างไว้ก่อน)
